# Minesweeper-XP 项目计划（Python + PySide6）

> 更新日期：2026-08-25
> 状态：计划已定稿，等待按阶段实施

## 一、摘要

用 Python + PySide6（≥6.10，支持 Python 3.14）完整复刻 Windows XP 扫雷（WINMINE 5.1）的玩法与 UI，直接使用从原版 `WINMINE.EXE` 提取的位图、图标、音效资源，达到像素级一致。修复原版“窗口不可缩放”缺陷，并扩展高分记录、音效开关、键盘操作、主题数据文件、语言切换五项功能。

游戏逻辑（core）与界面（ui）严格分层，配置与文案全部数据驱动（JSON），所有函数/类字段带详细中文注释（遵循 AGENTS.md 规范），文档与代码同步维护。开发全程遵守 AGENTS.md：不自动执行测试；仅修改注释不触发代码审查；`other/` 目录不入 Git。

## 三、复刻规格（UI 与玩法基准）

### 窗口与 HUD

- 标题“扫雷”，XP 灰色（#C0C0C0）3D 质感，外框 3px 内凹。
- HUD 面板 (9,9)-(W-10,45)，棋盘面板 (9,52)-(W-10,H-10)，均为 3px 内凹（常量与原版一致）。
- 左上 3 位 LED 计数器（数字位 13×23，x=17/30/43，y=16），中间 24×24 笑脸（居中，y=15），右上 3 位计时器。
- 方块 16×16，棋盘从 (12,55) 起、每格 +16；等价公式：col×16−4、row×16+39。

### 菜单（原版结构，默认中文文案）

- 游戏：新游戏(F2) / 初级 / 中级 / 高级 / 自定义… / 声音☑ / 标记☑ / 颜色☑ / 最佳时间… / 退出
- 帮助：帮助主题 / 搜索帮助 / 使用帮助 / 关于扫雷

### 玩法规则

- 左键翻开；右键循环“无→旗→问号→无”（“标记”关闭时仅旗→无）；中键或左右键同按对数字格做 3×3 chord。
- 首次点击保证其 3×3 邻域无雷；首次点击后开始计时，胜利/失败停止。
- 难度：初级 9×9/10、中级 16×16/40、高级 16×30/99；自定义行 9–24、列 9–30、雷 10 至 rows×cols−9，非法值拒绝。
- 胜负表现：失败显示红底雷、其余雷与错旗、哭脸；胜利全翻开、墨镜脸、刷新纪录弹输入名字对话框；最佳时间对话框显示三档成绩并可重置。

### 修复的原版缺陷

窗口可自由缩放，内容按统一缩放因子绘制（不拉伸），支持 50%–300% 与高分屏（devicePixelRatio）清晰渲染；缩放采用最近邻插值保持像素风。

## 四、实现方案

### 架构分层

- `core`（纯 Python，无 Qt 依赖）：`Cell`（状态机）、`Board`（布雷/首击安全/翻开扩散/chord/胜负）、`Game`（Ready/Playing/Won/Lost、计时、事件）、`Difficulty`（三档预设与自定义校验）。
- `data`：JSON 加载校验层（难度、主题、语言包、用户配置 → 类型明确的数据类，字段缺失或非法时回退默认值）。
- `ui`：`BoardWidget`（按 scale 绘制方块、鼠标/键盘事件、坐标换算）、`HudWidget`（LED 数字与笑脸）、`MainWindow`（菜单/布局/缩放/对话框/语言切换）、`SpriteLoader`（加载并缓存位图，处理自下而上翻转与单色切换）。
- `audio`：QtMultimedia 播放 `res/sounds/` 三个音效，受“声音”菜单与音量控制。
- 入口 `python -m minesweeper_xp`；依赖管理 pyproject.toml + venv + pip。

### 数据驱动与语言

- `res/difficulties.json`：三档难度预设。
- `res/themes/classic_xp.json`：主题文件（颜色表、尺寸、精灵路径、可选字体），v1 内置经典 XP 主题，菜单可选主题。
- `res/locales/zh_CN.json`（默认）与 `en_US.json`：全部界面文案；`MainWindow` 提供“语言”菜单即时切换（retranslateUi 模式）并写入用户配置。
- 用户配置存 `QStandardPaths.AppDataLocation/minesweeper_xp/config.json`：每难度 Top 5 高分、语言、主题、音效开关/音量、窗口尺寸与缩放比例。

### 扩展功能（v1）

- 高分记录：每难度 Top 5 + 最佳时间对话框（可重置）；新纪录输入名字（默认“匿名”）。
- 音效开关与音量（原版“声音”菜单项）。
- 键盘操作：方向键移动焦点、空格翻开、F 标记循环、Enter 3×3 chord、F2 新游戏、Ctrl+滚轮缩放。
- 主题数据文件 + 即时切换。
- 语言切换（中文/English，默认中文）。
